# Parampara

> Sovereign, offline-first family tree lineage web application.

## Overview
Parampara reimagines family trees into fluid, interactive canvases with private, on-device storage (IndexedDB) and authentic top-down **Descendants Flow** generational visualization.

## Features
- **Descendants Flow Hierarchy**: Ancestors honored at the top, generations cascading downward, and spouses side-by-side with offspring centered.
- **Sovereign Privacy**: 100% client-side data persistence in browser IndexedDB. Export JSON time-capsules anytime.
- **Craft Aesthetics**: Polished typography, glassmorphism, responsive canvas with pan/pinch/zoom, and archival print posters.

## Tech Stack
- **React 19** + **TypeScript** + **Vite 8**
- **Tailwind CSS v4**
- **@xyflow/react** for canvas visualization
- **Dexie.js** (IndexedDB)
- **Framer Motion**

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
